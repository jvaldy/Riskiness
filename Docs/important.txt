Commandes et infos importantes

Technologies de reference :
- Symfony 6.4
- PHP 8.1+
- YAML pour la configuration Symfony
- Tailwind CSS pour l'implementation UI
- Lucide pour les icones SVG
- Tokens centralises dans `webapp/config/design-system/`
- Charte graphique centralisee dans `Docs/`
- Pas de React ni de Next.js dans l'etat actuel du depot

URL locale : http://127.0.0.1:8000/
Serveur : PHP dev server sur `webapp/public`

Commandes utiles :
- Cloner depuis GitHub : `git clone <URL_DU_DEPOT_GITHUB>`
- Aller dans le projet : `cd Riskiness`
- Aller dans l'app : `cd webapp`
- Installer les dependances : `composer install`
- Installer les dependances de prod : `composer install --no-dev --optimize-autoloader`
- Lancer Symfony en local : `php -S 127.0.0.1:8000 -t public`
- Arreter Symfony : `Ctrl+C` si le serveur tourne au premier plan
- Arreter un serveur lance en arriere-plan : `Stop-Process -Name php` si aucun autre PHP ne tourne
- Voir l'etat Symfony : `php bin/console about`
- Vider le cache : `php bin/console cache:clear`
- Passer en prod : `APP_ENV=prod` et `APP_DEBUG=0`
- Compiler les variables d'environnement pour la prod : `composer dump-env prod`
- Vider le cache de prod : `php bin/console cache:clear --env=prod`
- Verifier la config prod : `php bin/console about --env=prod`

Emplacements a modifier :
- `webapp/.env.example` : template a versionner, a garder sans secret reel.
- `webapp/.env.local` : valeurs locales privees, a creer a partir du template.
- `webapp/.env.prod` : reference de production sans secret reel.
- `webapp/config/packages/framework.yaml` : la cle `APP_SECRET` est lue ici.
- `webapp/public/index.php` : entree web de l'application.
- `webapp/bin/console` : entree CLI pour les commandes de cache et de diagnostic.

Process dev :
1. Cloner le depot depuis GitHub.
2. Aller dans le projet puis dans `webapp`.
3. Copier le template vers le fichier local :
   `copy .env.example .env.local`
4. Modifier `webapp/.env.local`.
5. Installer les dependances :
   `composer install`
6. Lancer le serveur local :
   `php -S 127.0.0.1:8000 -t public`
7. Verifier l'etat :
   `php bin/console about`

Process prod :
1. Cloner le depot depuis GitHub sur la machine ou le serveur cible.
2. Aller dans `webapp`.
3. Definir `APP_ENV=prod`, `APP_DEBUG=0` et `APP_SECRET` dans l'environnement de la machine ou du conteneur.
4. Installer les dependances de prod :
   `composer install --no-dev --optimize-autoloader`
5. Si la prod repose sur des fichiers `.env`, partir de `webapp/.env.prod`.
6. Compiler les env si necessaire :
   `composer dump-env prod`
7. Vider le cache :
   `php bin/console cache:clear --env=prod`
8. Verifier :
   `php bin/console about --env=prod`
9. Redemarrer le service web si necessaire.

Commandes Git utiles :
- Voir l'etat du depot : `git status`
- Voir les changements : `git diff`
- Voir l'historique : `git log --oneline --decorate -n 20`
- Voir la branche courante : `git branch --show-current`
- Preparer un commit : `git add .`
- Creer un commit : `git commit -m "message"`
- Envoyer les changements : `git push`
- Recuperer les dernieres modifications : `git pull --rebase`
- Forcer un push apres recriture d'historique : `git push --force-with-lease`
